# SprintRunner
 Sprint Runner is a Python-based modular productivity system that helps users structure their work using configurable time sprints, breaks, and reusable routines.

## Features
- Customizable work/break intervals
- Reusable timer templates
- Different alarm tones for work vs breaks
- Built with OOP principles

## Tech Stack
- Python 3.10+
- Kivy (GUI)
- SQLite (data storage)
