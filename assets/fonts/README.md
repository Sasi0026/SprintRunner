# Fonts

`materialdesignicons-webfont.ttf` is the [Material Design Icons](https://pictogrammers.com/library/mdi/)
icon font by Pictogrammers (the copy bundled with KivyMD 1.2.0). See
https://pictogrammers.com/docs/general/license/ for its license.

The app uses it for all icons (`src/ui/icons.py`), because Kivy's default font has no emoji.
