# SprintRunner - Class Design

## Core Classes

### 1. Task
**Purpose:** Represents a single task/timer configuration
**Attributes:**
- name (str)
- total_duration_minutes (int)
- work_block_minutes (float)
- break_block_seconds (int)

**Methods:**
- `__init__()` - Create new task
- `validate()` - Check if settings are valid
- `to_dict()` - Convert to dictionary for saving
- `from_dict()` - Load from dictionary

---

### 2. TimeBlock (Base Class)
**Purpose:** Abstract base for work/break blocks
**Attributes:**
- duration_seconds (int)
- block_type (str)

**Methods:**
- `start()` - Begin countdown
- `get_remaining_time()` - Time left

---

### 3. WorkBlock (inherits TimeBlock)
**Purpose:** Represents work interval
**Additional:**
- alarm_tone = "work_alarm.mp3"

---

### 4. BreakBlock (inherits TimeBlock)
**Purpose:** Represents break interval
**Additional:**
- alarm_tone = "break_alarm.mp3"

---

### 5. Schedule
**Purpose:** Manages sequence of blocks
**Attributes:**
- task (Task)
- blocks (list of TimeBlock)

**Methods:**
- `generate_blocks()` - Create all work/break blocks
- `get_next_block()` - Return next block to run
- `is_complete()` - Check if done

---

### 6. Timer
**Purpose:** Controls countdown and alarms
**Attributes:**
- current_block (TimeBlock)
- is_running (bool)

**Methods:**
- `start()`
- `pause()`
- `stop()`
- `tick()` - Called every second
